# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in CodeWhy:

1. **Do not open a public issue.**
2. Send an email to `security@overfitlabs.com` or create a private GitHub Advisory via the repository's Security tab.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We take security reports seriously and will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
